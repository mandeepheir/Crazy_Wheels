# Crazy Wheels
2D browser platformer. Open index.html in a modern browser (no server or install needed).
Controls: Arrows/WASD run, Space jump (twice for a double jump), Shift boost, Esc pause. Touch buttons appear on phones.
Structure: storage.js (save data, skins), effects.js (sound + particles), levels.js (5 levels), player.js (physics), ui.js (menus), game.js (loop, world, drawing), main.js (wiring).
